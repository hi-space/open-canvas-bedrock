# 파일 기반 글쓰기 작업실

> 현재 홈은 [프로젝트·대화 통합 작업실](./cloud-workspace.md)로 확장되었습니다.
> 아래 내용은 이전 로컬 작업실의 저장 방식과 호환 동작에 관한 기록입니다.

홈(`/`)에서 Markdown 파일을 열고, AI 수정안을 검토하고, 승인한 내용을 파일로 저장합니다. 기존 대화·아티팩트 기능은 `/canvas`에서 계속 사용할 수 있습니다.

운영 사이트는 `https://canvas.hi-yoo.com`이며, 기존 Cognito 계정으로 로그인합니다. 운영 배포와 실제 모델·참고 글 추출 검증은 [배포 기록](./deployment/canvas-hi-yoo.md)에 정리되어 있습니다.

## 시작하기

1. **폴더 연결**에서 Claude Code나 Codex로 글을 작성하는 폴더를 선택합니다. 폴더 연결을 지원하지 않는 브라우저에서는 **파일 가져오기**를 사용합니다.
2. 왼쪽 목록에서 문서를 선택합니다. **읽기**는 문서 형태로 보여 주고, **Markdown 편집**은 원본을 직접 수정합니다.
3. 문장이나 문단을 선택하고 **교정**, **명확하게**, **간결하게**, 또는 직접 입력한 수정 요청을 실행합니다.
4. 원문과 수정안을 비교하고 변경별로 **승인**하거나 **거절**합니다. **모두 승인**과 **모두 거절**도 제공합니다.
5. **파일 저장**으로 초안을 연결한 파일에 기록합니다. `Ctrl/Cmd+S`는 저장, `Ctrl/Cmd+Shift+S`는 다른 이름으로 저장입니다.

AI 초안 생성은 **새 문서**를 만든 뒤 오른쪽 입력란에 주제와 요구사항을 적으면 됩니다. 새 초안도 승인한 뒤 본문에 반영됩니다.

## 저장과 외부 변경

- **브라우저 초안 보관**: 문서, 수정안, 출처, 최근 30개 이력을 IndexedDB에 보관합니다. 브라우저 데이터를 삭제하면 이 보관본도 삭제됩니다.
- **파일 저장**: 명시적으로 저장해야 실제 파일이 바뀝니다. AI 수정안 생성 자체는 파일과 본문을 변경하지 않습니다.
- **외부 변경**: 활성 파일은 약 3초마다, 연결 폴더는 약 10초마다 확인합니다. 탭이 보이는 동안 확인하며, 포커스가 돌아왔을 때도 갱신합니다. 브라우저가 닫혀 있으면 감시하지 않습니다.
- **충돌**: 외부 변경은 현재 초안 위에 자동으로 덮어쓰지 않습니다. 비교 후 반영하거나 **현재 초안 유지**로 판단한 뒤 저장합니다.
- 저장 직전과 임시 쓰기 후에도 파일을 다시 읽어 충돌을 확인합니다. 이 확인은 운영체제의 원자적 비교·교체 잠금이 아니므로, 저장하는 순간 여러 도구가 동시에 파일을 쓰는 작업은 피하는 것이 좋습니다.
- 파일이 이동·삭제되거나 접근 권한을 잃어도 초안은 남습니다. 다시 연결하거나 다른 이름으로 저장할 수 있습니다.
- 다른 탭이 먼저 작업 공간을 저장하면 오래된 탭의 저장을 차단합니다. 해당 탭의 미보관 초안은 다운로드한 뒤 다시 열 수 있습니다.

지원 파일은 UTF-8 `.md`, `.markdown`, `.txt`이며, BOM과 기존 줄바꿈을 보존합니다. 폴더 탐색은 문서 200개, 파일당 2MB, 하위 폴더 깊이 8단계까지입니다. 숨김 폴더와 의존성·빌드 폴더는 건너뛰며, 제한에 걸린 항목을 안내합니다. AI 검토는 문서 20만 자까지 지원합니다.

로컬 폴더 연결에는 브라우저의 File System Access API가 필요합니다. HTTPS 또는 localhost에서 사용하고 브라우저의 폴더 권한을 허용하세요. 지원 여부를 화면에서 확인하며, 미지원 환경에는 가져오기와 다운로드를 제공합니다.

## 출처와 교정 원칙

**출처** 탭에 원문 URL을 추가하면 제목과 발췌를 불러올 수 있습니다. 서버에 Firecrawl이 구성되어 있지 않거나 링크를 읽을 수 없으면 제목과 발췌를 직접 입력합니다. 참고 자료는 최대 50개이며, 발췌는 자료당 2만 자, AI 요청 전체에서 10만 자까지입니다.

문장을 선택하고 **인용 넣기**를 누르면 문장 뒤에 `[번호](URL "제목")` 형식의 Markdown 링크가 삽입됩니다. 읽기 화면에서 인용을 클릭하면 원문을 새 탭으로 엽니다. 일반 링크, 참조형 링크, 각주 안의 링크도 출처 목록에서 확인할 수 있습니다.

AI는 제공한 발췌를 근거로 사용합니다. URL만 제공한 자료를 읽었다고 가정하지 않습니다. 기존 인용 삭제, 근거 없는 새 링크, 잘린 응답은 검토안으로 반영하지 않습니다. 출처를 다른 문장으로 이동하는 수정은 **모두 승인**하거나 새 위치의 인용을 먼저 승인해야 기존 인용을 제거할 수 있습니다.

`docx` 스킬의 변경 추적 원칙을 참고해 수정된 부분만 표시하고 주변 문장을 함께 보여 줍니다. Markdown이 원본 형식이며, DOCX 가져오기·내보내기는 이번 구현에 포함하지 않습니다.

교정 문체는 `apps/web/src/lib/workspace/review-policy.ts`에서 조정할 수 있습니다. 기본값은 사실, 출처, 의미, 원래 문체를 보존하는 최소 교정입니다.

## 실행과 모델 설정

프런트엔드 실행:

```bash
cd apps/web
yarn install --frozen-lockfile
yarn dev
```

백엔드 실행은 [백엔드 README](../apps/backend/README.md)를 참고하세요. 프런트엔드는 같은 출처의 `/api` 경로로 요청하고, Next.js 서버가 기본 `http://localhost:9000`의 FastAPI로 전달합니다. 서버 환경변수 `API_URL` 또는 `FASTAPI_API_URL`로 백엔드 주소를 변경할 수 있습니다.

기본 모델은 `global.anthropic.claude-opus-5-5`입니다. `BEDROCK_MODEL_ID`와 `BEDROCK_REGION`은 서버에서 설정하며, 브라우저에서 AWS 자격증명을 입력하지 않습니다.

- [모델, 리전, 백엔드 버전 검증 기록](./bedrock-models.md)
- [프런트엔드 버전 및 호환성 변경 기록](./dependency-upgrade.md)

## 검증

```bash
cd apps/web
yarn test
yarn typecheck
yarn lint
yarn build
```

브라우저 통합 검증은 개발 서버를 실행한 뒤 Python Playwright와 Chromium이 설치된 환경에서 저장소 루트를 기준으로 실행합니다.

```bash
OPEN_CANVAS_TEST_URL=http://127.0.0.1:3000 python3 apps/web/tests/workspace_smoke.py
```

통합 검증은 AI·스크래핑 응답을 대체하고 실제 IndexedDB 및 OPFS 파일 핸들을 사용합니다. 파일 가져오기, 선택 교정, 승인·거절, 새로고침, 파일 전환 중 응답, 인용·다운로드, 외부 변경·충돌·복구, 모바일 화면을 확인합니다. 결과와 스크린샷은 기본 `/tmp/open-canvas-workspace`에 저장합니다.

개발용 브라우저 검증은 모의 응답을 사용합니다. 별도로 운영 ECS 태스크 권한을 사용한 실제 Global Opus 5.5 교정, DynamoDB 저장·조회·정리, Firecrawl 참고 글 추출을 확인했습니다. 네이티브 폴더 선택 권한은 각 사용자의 브라우저에서 허용해야 합니다.

File System Access API 참고: [Chrome 공식 문서](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access/).
